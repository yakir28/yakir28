# /brag: Shopify, explainer cut (matches the reference ad)

**Reference:** "Product Demo Video | SaaS Explainer Video | Infinity" (16:9, 19.1s, about 123 BPM). This cut copies its structure and look in Shopify's 9:16 format:

| Reference beat | Shopify version |
|---|---|
| Lavender background, blurred blue to magenta orbs, white dots, squiggles | Same palette and motion language (`#EDEFFA` background, orbs `#9DBBFF → #8C7BFF → #C64DF2 → #FF8CC6`), Montserrat |
| App-icon bubbles + typed "Forget switching between multiple tools!" | Generic commerce-tool bubbles (payments, shipping, email, chat, inventory...) + typed "Forget juggling apps to run your store!" |
| Live-action office shot + "Productivity" toggle | "Simplicity" toggle switches on, and the bubbles get pulled into one window (no stock footage) |
| Product window with colored views (Calendar/Columns/Gantt/List/Table), side windows blurred, round view buttons, a hand cursor tapping | A Shopify admin window (demo store "Bloom & Brew") with Store (green), Orders (blue), Products (yellow), Analytics (purple) and Customers (pink) views. The same blurred carousel, buttons and hand cursor tap. One view per bar (2s at 120 BPM) |
| Avatars popping around the first view | Customer avatars with "+ $48.00"-style order chips |
| Logo assembles, letters spread in, URL, purple pill CTA + hand click | Bag mark assembles from pieces, "shopify" letters converge, www.shopify.com, green "Start for free" pill + hand click |

**Format:** 1080×1920, 30fps, 19.0s.

## Storyboard
| Time | Beat |
|---|---|
| 0.0–1.0 | Orbs, particles and squiggles draw in. Ten tool bubbles pop in |
| 1.0–3.5 | "Forget juggling apps / to run your store!" types on and holds |
| 3.5–4.5 | "Simplicity" plus a toggle that flips on in Shopify green |
| 4.2–5.0 | The bubbles get pulled into the center and the admin window springs open |
| 5.0–7.0 | **Launch your store.** Store View: storefront builds and customer avatars pop around it |
| 7.0–9.0 | **Track every order.** Orders View: rows stagger in and #1006 flips Unfulfilled → Fulfilled |
| 9.0–11.0 | **Manage every product.** Products View: inventory bars fill, one low-stock item in pink |
| 11.0–13.0 | **See what's selling.** Analytics View: KPIs count up and weekly bars grow |
| 13.0–15.0 | **Know your customers.** Customers View: the customer table |
| 15.0–19.0 | Logo assembles, then www.shopify.com, then "Start for free" with the hand click |

Numbers, names and emails in the demo store are illustrative (`@example.com`). There are no real customer logos, stats or testimonials. Copy is based on Shopify's public positioning, because shopify.com was blocked by this environment's network policy.

## Sound
An original 120 BPM corporate-pop track in C (C–Am–F–G), electric-piano stabs, pad, bass. Snaps build through the intro, then the full beat drops when the window opens at 5.0s. Effects are in key: bubble pops climb the scale, typing ticks, toggle click, a whoosh for the pull-in, a tap and slide on each view change, logo sparkle, CTA click and a closing chord.
