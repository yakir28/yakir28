# /brag: monday.com, explainer cut (matches the Infinity reference ad)

**Format:** 1080×1920, 30fps, 19.0s. Same structure, palette and timing as the reference "SaaS Explainer Video | Infinity" (lavender background, blue to magenta orbs, tool bubbles, typed hook, toggle, color-coded view carousel with a hand cursor, logo/URL/CTA outro).

**Source:** monday.com was blocked by this environment's network policy. Copy comes from monday.com's public messaging ("work management platform", "Get Started", "Free forever. No credit card needed.") and its familiar product language: boards, status columns (Done / Working on it / Stuck), Main Table, Kanban, Timeline, Calendar and Dashboard views. Brand colors: `#6161FF` purple CTA, logo marks `#FF3D57` / `#FFCB00` / `#00CA72`, statuses `#00C875` / `#FDAB3D` / `#E2445C`. Font: Poppins. The board, people and numbers are illustrative.

## Storyboard
| Time | Beat |
|---|---|
| 0.0–1.0 | Orbs, particles and squiggles. Ten tool bubbles pop in (spreadsheets, email, chat, docs, calendar, to-dos, clocks...) |
| 1.0–3.5 | "Forget switching / between tools!" types on and holds |
| 3.5–4.5 | "Teamwork" plus a toggle that flips on in monday purple |
| 4.2–5.0 | The bubbles get pulled in and the board window springs open |
| 5.0–7.0 | **Plan every project.** Main Table: task rows with owners and status pills, "Design landing page" flips Stuck → Done, and teammate avatars pop up with "✓ Done", "@mentioned you", "✓ Approved" |
| 7.0–9.0 | **Move work forward.** Kanban: "QA mobile app" lifts out of Working on it and drops into Done |
| 9.0–11.0 | **See every deadline.** Timeline: Gantt bars grow across Oct–Dec with a today line |
| 11.0–13.0 | **Never miss a date.** Calendar: October events pop onto the grid |
| 13.0–15.0 | **Track it all in one place.** Dashboard: KPIs count up, the status donut draws and weekly bars grow |
| 15.0–19.0 | The logo marks assemble, the "monday.com" letters converge, then "Work management for every team", then the hand clicks "Get Started →", then "Free forever. No credit card needed." |

## Sound
An original 120 BPM corporate-pop track in C, with the full beat dropping when the window opens. Effects are in key: bubble pops, typing ticks, toggle click, pull-in whoosh, a tap and swoosh on each view change, a chime on the status flip, the Kanban card drop, calendar pops, logo sparkle and the CTA click.
